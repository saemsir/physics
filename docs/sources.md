# Source library and attribution policy

The `books/` directory is intended as a research library, not as a source of
material to copy into scripts, images, or videos. For every episode, record
the specific source, author, edition, section or page, stable URL when
available, date consulted, and applicable license or permission.

## Rules for research use

- Verify important claims against a derivation, an independent source, or a
  trusted reference. An AI-generated summary is not verification.
- Distinguish the source's statement from the episode's original explanation
  or inference.
- Create original narration, examples, diagrams, and animation. Do not
  reproduce a book's expressive text or figures unless the applicable license
  or permission allows it.
- Check the license and attribution requirements for each item before
  downloading, transforming, or publishing it. A file in this repository is
  not automatically cleared for redistribution.
- Note uncertainty, conflicting conventions, and any unresolved physics
  review in the episode record.
- Never put credentials, private student information, or unrelated personal
  data into the source library or AI prompts.
