# Episode brief: vectors_001

- **Working title:** A vector is two moves
- **Primary audience:** NEET / JEE; useful as a general physics refresher
- **Language:** To be confirmed before narration recording
- **Target duration:** 30-60 seconds for the first visual milestone
- **Central question:** How can two simpler moves reproduce one diagonal vector?
- **Learning outcome:** Read the signed horizontal and vertical components
  from a Cartesian diagram and express the vector using unit vectors.
- **Prerequisites:** Cartesian axes and directed vectors
- **Likely misconception:** Components are separate vectors whose magnitudes
  can be added as ordinary numbers to get the diagonal magnitude.
- **Scope and non-goals:** Positive x and y components only; angle-based
  trigonometry and negative-component cases are follow-up material.
- **Key claim:** The vector is the vector sum of its Cartesian components.
- **Success criteria:** The learner can identify each component's direction
  and write the vector decomposition after viewing the scene.
