# Physics review: vectors_001

## Claim and model

- **Claim:** A Cartesian vector is the sum of its x- and y-component vectors.
- **Definitions:** The diagram uses a right-handed Cartesian coordinate
  system. `A_x` and `A_y` are signed scalar components; `i-hat` and `j-hat`
  are unit vectors in the positive x and y directions.
- **Assumptions:** The displayed vector is two-dimensional and the axes are
  orthogonal. The grid is schematic; coordinates are in arbitrary diagram
  units, not physical length units.
- **Domain:** Any two-dimensional vector in this Cartesian basis.
- **Derivation:** Resolve the tip displacement `(3, 2)` into `(3, 0) + (0, 2)`.
  Therefore `A = 3 i-hat + 2 j-hat`, and the component arrows add tip-to-tail
  to the original arrow.

## Verification

- **Units:** `A_x` and `A_y` have the same units as `A`; the unit vectors are
  dimensionless.
- **Direction:** Both components are positive for the shown tip `(3, 2)`.
- **Magnitude check:** `|A| = sqrt(A_x^2 + A_y^2) = sqrt(13)` diagram units,
  not `A_x + A_y`.
- **Independent check:** Adding the component displacements gives `(3, 0) +
  (0, 2) = (3, 2)`, the plotted endpoint.
- **Source:** Standard Cartesian vector decomposition; add the teacher's
  preferred reference before release.
